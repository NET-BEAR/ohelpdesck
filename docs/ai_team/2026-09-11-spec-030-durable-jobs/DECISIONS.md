# Решения SPEC-030

## DG-030-01: event без handler

Дата: 2026-09-11. Принят вариант A: неизвестный/незарегистрированный handler
не создаёт job и не получает receipt. Event остаётся в `outbox_events` как
наблюдаемый durable факт. Причина: новый handler может быть введён позднее и
должен иметь возможность обработать историческое событие по явному backfill.
