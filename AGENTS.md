# Правила проекта

- Модульный монолит, отдельные процессы API и worker.
- PostgreSQL — источник истины; Redis не хранит единственную копию durable данных.
- Модели внешних провайдеров не проникают в core.
- Цикл: spec → acceptance tests → RED → минимальная реализация → GREEN → независимый review → QA.
- Транзакциями явно управляет application service.
- Ошибки не игнорируются молча; HTTP disconnect допустим после отправки ответа.
- Каждый внешний вызов ограничен timeout/context.
- Не читать .env и не логировать секреты, DSN, headers, provider responses.
- Новые зависимости требуют обоснования.
- Изменение HTTP требует обновления api/openapi.yaml.
- Документация задачи хранится в docs/ai_team; PLANS.md меняет только оркестратор.
